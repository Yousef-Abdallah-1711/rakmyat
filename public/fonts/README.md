# RAKMYAT web fonts

These self-hosted WOFF2 subsets are used to keep English and Arabic font
requests scoped to their locale. The English layout preloads only Space
Grotesk and Inter; IBM Plex Mono loads when the page uses technical labels.
The Arabic layout loads IBM Plex Sans Arabic on demand.

The files were subsetted and optimized from the official Google Fonts and IBM
Plex font distributions. Their licenses and copyright notices are included
beside the assets:

- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- IBM Plex: https://github.com/IBM/plex
